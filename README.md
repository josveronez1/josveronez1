### 🚀 No que ando mexendo

- Sistema de gestão com arquitetura modular (DDD, multi-tenancy, máquina de estados) rodando em Java/Spring Boot + React + PostgreSQL
- Servidor doméstico configurado do zero: hardening de SSH, rede com Docker, reverse proxy, monitoramento — pra hospedar meus próprios projetos sem depender de cloud
- Integrações backend em ambiente ERP: migrações de API, automações de atendimento, soluções de UI para dados sensíveis
- Explorando arquitetura hexagonal e boas práticas de design em Java
